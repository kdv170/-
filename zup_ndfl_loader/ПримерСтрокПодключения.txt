# Примеры строк COM-подключения к ЗУП
# Эти строки собирает функция ПостроитьСтрокуСоединения() автоматически.
# Файл — шпаргалка для ручной проверки через "Тест подключения" / консоль.
# Кавычки внутри пути экранируются удвоением (стандарт 1С).

# --- 1. Файловая база, без авторизации Windows (вариант по умолчанию) ---
File="C:\Bases\ZUP"; Usr="Администратор"; Pwd="123";

# --- 2. Файловая база на сетевом ресурсе ---
File="\\srv-files\1c-bases\zup_prod"; Usr="ОбменERP"; Pwd="S3cret!";

# --- 3. Клиент-серверная база, нестандартный порт ---
Srvr="srv1c:2541"; Ref="zup_prod"; Usr="ОбменERP"; Pwd="S3cret!";

# --- 4. Клиент-серверная база, сервер и порт по умолчанию ---
Srvr="srv1c"; Ref="zup"; Usr="Администратор"; Pwd="";

# --- Примечания ---
# 1) Пользователь ЗУП должен иметь права на чтение:
#    регистров УчетДоходовДляИсчисленияНДФЛ и РасчетыНалогоплательщиковСБюджетомПоНДФЛ,
#    справочников ФизическиеЛица и Организации.
# 2) Разрядность клиента ERP и COM-коннектора обязаны совпадать:
#    32-битный клиент -> 32-битный comcntr.dll, 64-битный -> 64-битный.
#    Симптом рассогласования: "Недопустимая строка с указанием класса".
# 3) Для серверной ЗУП с Windows-аутентификацией строка короче, но обработка
#    всегда передает Usr/Pwd явно — заведите в ЗУП сервисного пользователя.
# 4) Пароль нигде не сохраняется: живет только в поле формы и в памяти
#    во время Connect(). Не давайте сервисному пользователю полных прав.
