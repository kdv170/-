# Форма `ФормаЗагрузки` — что создать в Конфигураторе

Управляемая форма внешней обработки. Ниже — точный список реквизитов,
таблиц и команд. **Имена обязаны совпадать** с обращениями в
`ManagedFormModule.bsl` и `ObjectModule.bsl`, иначе форма не запустится.

## 1. Реквизиты формы (данные объекта обработки)

Создайте в ветке обработки реквизиты (все — на уровне самой обработки,
не формы, чтобы код `Объект.*` их видел):

| Имя | Тип | Назначение |
|---|---|---|
| `ВариантИБЗУП` | Строка | `Файловая` или `Клиент-серверная`. На форме — переключатель |
| `ПутьКБазеЗУП` | Строка (длина 255) | Каталог файловой базы ЗУП, напр. `C:\Bases\ZUP` |
| `СерверЗУП` | Строка (длина 100) | Сервер 1С ЗУП, напр. `srv1c:1541` |
| `ИмяБазыЗУП` | Строка (длина 100) | Имя базы на сервере, напр. `zup_prod` |
| `ПользовательЗУП` | Строка (длина 100) | Логин пользователя ЗУП |
| `ПарольЗУП` | Строка (длина 100) | Пароль (поле с `РежимПароля = Истина`) |
| `COMОбъект` | Строка | ProgID коннектора: `V83.COMConnector` или `V82.COMConnector` |
| `Организация` | `СправочникСсылка.Организации` | Организация ERP (шапка документа + отбор в ЗУП по наименованию) |
| `НачалоПериода` | Дата (состав: Дата) | Начало выгрузки по полю `Период` регистра |
| `КонецПериода` | Дата (состав: Дата) | Конец выгрузки (в запрос уходит `КонецДня`) |
| `ИмяРегистраЗУП` | Строка (длина 100) | Имя регистра в ЗУП, по умолчанию `УчетДоходовДляИсчисленияНДФЛ` |
| `СоздаватьНеНайденныхФизлиц` | Булево | Создавать элементы `ФизическиеЛица`, если не найдены |
| `ДанныеЗУП` | ТаблицаЗначений | Таблица выгруженных строк (колонки — ниже) |

Колонки ТЗ `ДанныеЗУП` (создавать в том же порядке):

| Имя колонки | Тип | Примечание |
|---|---|---|
| `Включать` | Булево | Флаг — строка попадет в документ |
| `ФизЛицоНаименование` | Строка (150) | ФИО из ЗУП |
| `ФизЛицоИНН` | Строка (12) | ИНН из ЗУП (может быть пустым) |
| `ФизЛицоДатаРождения` | Дата | Для разбора дублей ФИО |
| `ФизЛицоERP` | `СправочникСсылка.ФизическиеЛица` | Сопоставленная ссылка ERP (заполняется автоматически) |
| `ДатаПолученияДохода` | Дата | Из регистра ЗУП (fallback — `Период`) |
| `МесяцНалоговогоПериода` | Дата | Месяц налогового периода |
| `КодДохода` | Строка (10) | Код дохода НДФЛ (1010, 2000, …) |
| `КодВычета` | Строка (10) | Код вычета (126, 127, …) |
| `СуммаДохода` | Число (15, 2) | Начисленный доход |
| `СуммаВычета` | Число (15, 2) | Вычет |
| `СуммаНалога` | Число (15, 2) | Для регистра расчетов (в Доходы игнорируется, если нет такой колонки в ТЧ) |
| `ОрганизацияЗУП` | Строка (150) | Организация из ЗУП (информативно) |
| `Проблема` | Строка (255) | Служебная: причина несопоставления |

## 2. Элементы формы (пример раскладки)

```
Группа «Подключение к ЗУП» (обычная группа):
  - ВариантИБЗУП            (переключатель: Файловая / Клиент-серверная)
  - ПутьКБазеЗУП            (поле ввода; видимость = ВариантИБЗУП = Файловая)
  - СерверЗУП               (поле ввода; видимость = Клиент-серверная)
  - ИмяБазыЗУП              (поле ввода; видимость = Клиент-серверная)
  - ПользовательЗУП         (поле ввода)
  - ПарольЗУП               (поле ввода, РежимПароля)
  - COMОбъект               (выпадающий список: V83.COMConnector / V82.COMConnector)

Группа «Отбор» (обычная группа):
  - Организация             (поле ввода)
  - НачалоПериода           (поле ввода, вид Даты)
  - КонецПериода            (поле ввода, вид Даты)
  - ИмяРегистраЗУП          (поле ввода с кнопкой выбора из списка:
                             УчетДоходовДляИсчисленияНДФЛ,
                             РасчетыНалогоплательщиковСБюджетомПоНДФЛ)
  - СоздаватьНеНайденныхФизлиц (флажок)

Группа «Командная панель»:
  - ПодключитьсяИПолучитьДанные  (кнопка, основная)
  - СоздатьОперациюУчетаНДФЛ     (кнопка, основная)
  - ОтметитьВсе / СнятьВсеОтметки / ПоказатьТолькоПроблемные (кнопки)

Таблица «ДанныеЗУП» (таблица формы, источник — Объект.ДанныеЗУП):
  колонки по списку выше; ФизЛицоERP — с кнопкой выбора из справочника
  (ручное пере-сопоставление); Проблема — только просмотр.
```

## 3. Команды формы (имена = имена процедур в модуле формы)

| Команда | Действие | Кнопка |
|---|---|---|
| `ПодключитьсяИПолучитьДанные` | COM-подключение + запрос + сопоставление | «Подключиться и получить данные» |
| `СоздатьОперациюУчетаНДФЛ` | Создание документа ERP | «Создать Операцию учета НДФЛ» |
| `ОтметитьВсе` | `Включать = Истина` для всех | «Отметить все» |
| `СнятьВсеОтметки` | `Включать = Ложь` для всех | «Снять отметки» |
| `ПоказатьТолькоПроблемные` | Оставить включенными только несопоставленные | «Только проблемные» |

У каждой команды: **Действие** = вызов соответствующей процедуры модуля формы.

## 4. Проверки после создания формы

1. Синтаксический контроль модуля объекта и модуля формы (F7) — без ошибок.
2. В свойствах обработки: **Безопасный режим = Ложь**.
3. Основная форма назначена (`ФормаЗагрузки`).
4. Сохранение как `ЗагрузкаНДФЛизЗУП.epf`, регистрация в ERP через
   «Дополнительные отчеты и обработки».

## 5. Частые ошибки сборки

- **«Поле объекта недоступно»** — имя реквизита не совпало с таблицей выше.
  Сверьте каждое имя побуквенно (регистр важен только для чтения человеком,
  но опечатки критичны).
- **«Метод объекта не обнаружен: НайтиФизЛицо»** — в модуль объекта скопирован
  не весь `ObjectModule.bsl` (функции сопоставления — в конце файла).
- **COM error 0x800401F3** — неверный ProgID; поставьте `V83.COMConnector`
  и проверьте, что на машине установлен клиент 1С той же разрядности (x86/x64),
  что и запущенная ERP.
- **Пустая таблица после подключения** — проверьте период (поле `Период`
  регистра, не `ДатаПолученияДохода`) и отбор по организации: наименование
  в ERP должно в точности совпадать с наименованием в ЗУП.
