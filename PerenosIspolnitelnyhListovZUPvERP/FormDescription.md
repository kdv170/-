# Описание формы обработки «Перенос исполнительных листов ЗУП → ERP»

Создать в конфигураторе управляемую форму `Форма` и назначить её основной. Модуль формы — файл `ManagedFormModule.bsl`. Все реквизиты ниже — **реквизиты формы** (узел «Реквизиты» именно формы, не объекта обработки); в модуле формы они доступны по имени напрямую (`ДатаПереноса`, `НайденныеДокументы`, ...). Серверные процедуры формы вызывают экспортные функции модуля объекта (`ДействующиеИсполнительныеЛисты`, `ВыгрузитьВФайл`, `ЗагрузитьИзФайла`, `ПрямойПереносЧерезCOM`) без квалификации — для формы своей внешней обработки это штатный механизм.

## Реквизиты формы

| Имя | Тип | Назначение |
|---|---|---|
| `ДатаПереноса` | Дата (дата, 10.06) | Действующие **на конец этого дня** удержания попадают в перенос. По умолчанию — текущая дата |
| `Организация` | СправочникСсылка.Организации | Отбор. Пусто = по всем организациям |
| `ФайлОбмена` | Строка (неограниченная) | Путь к JSON-файлу обмена |
| `ОбновлятьСуществующие` | Булево | При загрузке перезаписывать реквизиты документов, найденных по ГУИДу. По умолчанию `Истина` |
| `ПроводитьДокументы` | Булево | Проводить создаваемые документы. По умолчанию `Истина`. Если `Ложь` — запись черновиком (`РежимЗаписиДокумента.Запись`) |
| `ТолькоПроведенные` | Булево | Выгружать только проведённые документы ЗУП. По умолчанию `Истина` |
| `ПодключениеСтрока` | Строка | Строка COM-подключения к базе ЗУП. Пример: `Srvr="srv1c";Ref="zup";Usr="Обмен";Pwd="***";` или `File="C:\bases\zup";Usr="Обмен";Pwd="***";` |
| `НайденныеДокументы` | Таблица значений | Результат отбора по регистру (см. колонки ниже). Колонка `Переносить` редактируется, остальные — только просмотр |
| `Протокол` | Строка (многострочная) | Протокол выполнения: заполнение, выгрузка, загрузка, прямой перенос |

## Колонки таблицы `НайденныеДокументы`

| Имя | Тип | Видимость / редактирование |
|---|---|---|
| `Переносить` | Булево | Редактируется (флажок) |
| `Документ` | ДокументСсылка.ИсполнительныйЛист | Просмотр. Ссылка на документ ЗУП (при прямом переносе / заполнении в ЗУП) |
| `ГУИД` | Строка (36) | Просмотр. `Строка(Документ.УникальныйИдентификатор())`. Скрыть можно, для загрузки обязателен |
| `Номер` | Строка (30) | Просмотр |
| `ДатаДокумента` | Дата | Просмотр |
| `Организация` | СправочникСсылка.Организации | Просмотр |
| `Сотрудник` | СправочникСсылка.Сотрудники | Просмотр |
| `ФизическоеЛицо` | СправочникСсылка.ФизическиеЛица | Просмотр |
| `Получатель` | Строка (150) | Просмотр. Представление получателя (контрагент или физлицо) |
| `ВидУдержания` | ПланВидовРасчетаСсылка.Удержания | Просмотр |
| `Размер` | Число (15, 5) | Просмотр. Процент / сумма / доля — как хранится в срезе регистра |
| `ДатаНачала` | Дата | Просмотр |
| `ДатаОкончания` | Дата | Просмотр |
| `Проведен` | Булево | Просмотр |

Все колонки, кроме `Переносить`, — `ТолькоПросмотр = Истина`, `РедактированиеТекста = Ложь`.

## Команды формы (кнопки командной панели)

| Имя команды | Заголовок | Действие (процедура модуля формы) |
|---|---|---|
| `ЗаполнитьПоРегистру` | Заполнить по регистру | `ЗаполнитьПоРегистру(Команда)` → сервер `ЗаполнитьПоРегиструНаСервере()` |
| `ВыгрузитьВФайл` | Выгрузить в файл | Диалог выбора файла → сервер `ВыгрузитьВФайлНаСервере()` |
| `ЗагрузитьИзФайла` | Загрузить из файла | Диалог выбора файла → сервер `ЗагрузитьИзФайлаНаСервере()` |
| `ВыполнитьПрямойПеренос` | Прямой перенос (COM) | `ВыполнитьПрямойПеренос(Команда)` → сервер `ВыполнитьПрямойПереносНаСервере()` |
| `ВыбратьФайлОбмена` | … (кнопка у поля) | `ВыбратьФайлОбмена` — диалог `*.json` |
| `ОтметитьВсе` / `СнятьВсе` | Отметить все / снять | Массовая установка флажка `Переносить` |

## Группы / закладки (рекомендуемая компоновка)

1. **Закладка «Отбор»**: `ДатаПереноса`, `Организация`, `ТолькоПроведенные`, кнопка `Заполнить по регистру`.
2. **Закладка «Документы»**: таблица `НайденныеДокументы` + `Отметить все / Снять все`.
3. **Закладка «Обмен»**: `ФайлОбмена` (+ кнопка выбора), `ОбновлятьСуществующие`, `ПроводитьДокументы`, кнопки `Выгрузить в файл` / `Загрузить из файла`.
4. **Закладка «Прямое подключение»**: `ПодключениеСтрока`, кнопка `Прямой перенос (COM)`.
5. **Закладка «Протокол»**: поле `Протокол` на всю ширину.

## Элементы, требующие ручной настройки типов

- `Организация` — составной тип не нужен, строго `СправочникСсылка.Организации` (иначе отбор в запросе не сработает).
- `ВидУдержания` в таблице — `ПланВидовРасчетаСсылка.Удержания`. Если в конфигурации план видов расчёта называется иначе — указать фактический тип (код сам определяет имя ПВР через метаданные, см. `ИмяПланаВидовРасчетаУдержаний()`).
- `Протокол` — реквизит формы типа Строка (многострочный, длинные строки). Вывод — процедурой `ВывестиВПротокол()` из модуля формы.

## Проверки при создании формы

- У всех серверных процедур, работающих с запросом/файлом/документами, стоит `&НаСервере` (уже расставлено в `ManagedFormModule.bsl`).
- Диалоги выбора файлов — только `&НаКлиенте` (`ВыгрузитьВФайл`, `ЗагрузитьИзФайла`, `ВыбратьФайлОбмена`).
- Таблица `НайденныеДокументы`: имена колонок один в один как в `ДействующиеИсполнительныеЛисты()` (`Переносить`, `Документ`, `ГУИД`, `Номер`, `ДатаДокумента`, `Организация`, `Сотрудник`, `ФизическоеЛицо`, `Получатель`, `ПолучательПредставление`, `ВидУдержания`, `Размер`, `ДатаНачала`, `ДатаОкончания`, `Проведен`) — иначе `Загрузить()` упадёт.
- `Протокол` — реквизит формы типа Строка, многострочный. Вывод — процедурой `ВывестиВПротокол()` из модуля формы.
