# Загрузка данных НДФЛ из ЗУП в 1С:ERP

Внешняя управляемая обработка переносит движения регистра накопления
`УчетДоходовДляИсчисленияНДФЛ` из 1С:ЗУП в открытую базу 1С:ERP через
`V83.COMConnector`.

Исходники находятся в `src/` в формате выгрузки внешней обработки 1С 8.3
(версия XML 2.17).

## Что делает обработка

- подключается к ЗУП по файловой или серверной строке соединения;
- проверяет наличие указанного регистра в ЗУП и ERP;
- выбирает регистраторы, у которых есть движения в заданном периоде;
- читает **все** движения каждого выбранного регистратора, чтобы не записать
  частичный набор;
- переносит измерения, ресурсы и реквизиты с совпадающими именами;
- преобразует ссылки по полному имени метаданных и UUID;
- сначала подготавливает все данные и только затем записывает их в одной
  транзакции;
- по умолчанию работает в тестовом режиме без записи.

## Критические условия

1. Документы-регистраторы и все ссылочные данные уже должны существовать в ERP
   с теми же UUID, что и в ЗУП. Обработка не создает документы и справочники.
2. Структура регистра в ЗУП и ERP должна совпадать по именам и типам полей.
3. При реальной загрузке существующий набор записей каждого регистратора в ERP
   **полностью замещается** набором из ЗУП.
4. Обработка поддерживает регистры накопления, подчиненные регистратору.
   Независимые регистры и регистры сведений не поддерживаются.
5. Запускать следует от пользователя ERP с правом записи регистра. Учетная
   запись ЗУП должна иметь право чтения регистра и метаданных.

Перед работой сделайте резервную копию ERP и сначала выполните тестовую
загрузку на копии базы.

## Сборка EPF

На Windows-машине с установленной платформой 1С выполните:

```bat
"C:\Program Files\1cv8\8.3.27.XXXX\bin\1cv8.exe" DESIGNER ^
  /F "C:\Bases\EmptyBuildBase" ^
  /LoadExternalDataProcessorOrReportFromFiles "C:\Work\src\ЗагрузкаДанныхНДФЛИзЗУП.xml" ^
  "C:\Work\build\ЗагрузкаДанныхНДФЛИзЗУП.epf" ^
  /DisableStartupDialogs ^
  /Out "C:\Work\build\build.log"
```

Для сборки нужна пустая служебная база с совместимой версией платформы.
В репозитории нет бинарного `.epf`, потому что его создает закрытый
Конфигуратор 1С, отсутствующий в Linux-окружении.

## Использование

1. В ERP откройте `Файл → Открыть` и выберите собранный `.epf`.
2. Введите строку COM-соединения с ЗУП. Примеры:

   ```text
   File="D:\Bases\ZUP";Usr="Обмен";Pwd="пароль";
   Srvr="server";Ref="zup";Usr="Обмен";Pwd="пароль";
   ```

3. Уточните техническое имя регистра. Значение по умолчанию —
   `УчетДоходовДляИсчисленияНДФЛ`.
4. Задайте период и максимальное количество строк.
5. Нажмите «Проверить подключение».
6. Оставьте «Тестовый режим» включенным и нажмите «Загрузить». Будут проверены
   все ссылки и типы без записи.
7. После успешной проверки снимите флаг тестового режима и повторите загрузку.

Тестовый режим создает и заполняет наборы записей только в памяти. Он не
вызывает `Записать()`, поэтому не запускает подписки на событие записи и не
может проверить ограничения, реализованные в таких подписках.

Пароль хранится только в реквизите открытой формы и не записывается в
информационную базу или файлы.

## Совместимость

- управляемое приложение 1С:Предприятия 8.3;
- Windows-сервер 1С или файловый клиент Windows с зарегистрированным
  `V83.COMConnector`;
- одинаковая разрядность процесса 1С и COM-компоненты;
- конфигурации ERP и ЗУП, в которых целевой регистр имеет совместимую
  структуру.
