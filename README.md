# Загрузка учета данных для НДФЛ из 1С:ЗУП в 1С:ERP

Внешняя обработка для **1С:ERP** (управляемые формы). Читает регистр учёта доходов для исчисления НДФЛ в **1С:ЗУП** через **COM-соединение** и записывает движения в ERP документом **«Перенос данных»**.

В ЗУП 3.1 / ERP 2.5 этот регистр называется `РегистрНакопления.СведенияОДоходахНДФЛ` (синоним: «Учет доходов для исчисления НДФЛ»). Обработка ищет его автоматически, в том числе по синониму «учет данных для НДФЛ».

## Состав поставки

```
src/
  ЗагрузкаУчетаДанныхДляНДФЛИзЗУП.xml      # корневые метаданные обработки
  ЗагрузкаУчетаДанныхДляНДФЛИзЗУП/
    Ext/ObjectModule.bsl                   # сопоставление НСИ и запись в ERP
    Forms/Форма.xml
    Forms/Форма/Ext/Form.xml
    Forms/Форма/Ext/Form/Module.bsl        # COM-подключение и чтение ЗУП
```

Файл `.epf` собирается в Конфигураторе из этой XML-выгрузки (платформа 8.3.20+, формат 2.17).

## Сборка .epf

1. Откройте **Конфигуратор** информационной базы **1С:ERP** (нужны справочники зарплатной подсистемы: `Организации`, `ФизическиеЛица`, `Сотрудники`, `ВидыДоходовНДФЛ` и документ `ПереносДанных`).
2. Соберите обработку командой:

```bat
1cv8.exe DESIGNER /S "Сервер\ERP" /N"Пользователь" /P"Пароль" /DisableStartupDialogs /LoadExternalDataProcessorOrReportFromFiles "src\ЗагрузкаУчетаДанныхДляНДФЛИзЗУП.xml" "build\ЗагрузкаУчетаДанныхДляНДФЛИзЗУП.epf"
```

Для файловой базы вместо `/S` укажите `/F "C:\Bases\ERP"`.

3. Либо в Конфигураторе: создайте внешнюю обработку с управляемой формой, скопируйте модули из `ObjectModule.bsl` и `Module.bsl`, затем перенесите реквизиты формы по `Form.xml`.

## Подключение в ERP

- **Файл → Открыть** — выбрать собранный `.epf`.
- Или **НСИ и администрирование → Печатные формы, отчеты и обработки → Дополнительные отчеты и обработки**.  
  Безопасный режим **выключить**: COM-объект в безопасном режиме не создаётся.

Запускать нужно в **тонком или толстом клиенте Windows**. Веб-клиент COM не поддерживает.

## Как пользоваться

1. Вкладка **Подключение к ЗУП** — файловая или клиент-серверная база, пользователь, COM-коннектор (`V83.COMConnector` / `V84` / `V85`).
2. **Проверить соединение**.
3. Вкладка **Отбор и параметры** — период, организация ERP (отбор в ЗУП по ИНН), флаги создания недостающих физлиц и сотрудников.
4. **Прочитать из ЗУП**.
5. **Сопоставить** — поиск в ERP по УИД, ИНН, СНИЛС, ФИО и дате рождения. Ненайденные физлица можно указать вручную в колонке «Физлицо ERP».
6. **Загрузить в ERP** — по каждому месяцу и организации создаётся документ `Перенос данных` с движениями регистра `СведенияОДоходахНДФЛ`.

## Сопоставление объектов

| Объект ЗУП | Поиск в ERP |
|---|---|
| Организация | выбранная в форме, иначе УИД / ИНН+КПП |
| Физическое лицо | УИД → ИНН → СНИЛС → ФИО+дата рождения |
| Сотрудник | УИД → физлицо + табельный номер |
| Подразделение | УИД → код/наименование владельца |
| Код дохода / вычета | `НайтиПоКоду` в `ВидыДоходовНДФЛ` / `ВидыВычетовНДФЛ` |
| Категория дохода | имя или синоним перечисления `КатегорииДоходовНДФЛ` |
| Регистрация в НО | код или КПП |

Состав полей регистра определяется по метаданным ЗУП: отсутствующие в конкретной версии реквизиты в запрос не попадают.

## Требования

- Одинаковая разрядность клиента 1С ERP и `comcntr.dll` (регистрация: `regsvr32 comcntr.dll` из каталога `bin` платформы).
- В ERP включена подсистема зарплаты и кадров (есть регистр `СведенияОДоходахНДФЛ` и документ `ПереносДанных`).
- Пользователь ЗУП имеет права на чтение регистра учёта НДФЛ.

## Ограничения

- Обработка переносит **учёт доходов для исчисления НДФЛ**, а не исчисленный/удержанный налог и не вычеты. Для полной картины 6-НДФЛ дополнительно нужны регистры `РасчетыНалогоплательщиковСБюджетомПоНДФЛ` и вычеты.
- Документы-основания ЗУП в ERP не создаются: регистратор — документ «Перенос данных».
- COM работает только на Windows-клиенте (или на сервере 1С, если коннектор зарегистрирован там).
