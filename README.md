# Загрузка данных по НДФЛ из 1С:ЗУП в 1С:ERP через COM-соединение

Внешняя обработка **«Загрузка данных по НДФЛ из ЗУП в ERP (через COM)»** (`ЗагрузкаДанныхНДФЛИзЗУП`) предназначена для конфигурации **«1С:ERP Управление предприятием 2»** (редакции 2.4 и 2.5, а также совместима с «1С:Комплексная автоматизация 2» и «1С:ЗУП 3.1»).

Обработка подключается по **COM-соединению** к информационной базе **«1С:Зарплата и управление персоналом 3.1»**, считывает записи из регистра налогового учета **«Учет доходов для исчисления НДФЛ»** (внутреннее имя регистра в метаданных: `РегистрНакопления.СведенияОДоходахНДФЛ`) и корректно загружает их в базу 1С:ERP.

---

```text

  ЗагрузкаДанныхНДФЛИзЗУП/
    Ext/
      ObjectModule.bsl                          Модуль объекта: сопоставление справочников,
                                                формирование документов ERP и прямая запись регистров
    Forms/
      Форма.xml                                 Манифест управляемой формы
      Форма/
        Ext/
          Form.xml                              Декларация управляемой формы (элементы, реквизиты, команды)
          Form/
            Module.bsl                          Модуль формы: клиент-серверное COM-взаимодействие,
                                                запросы к базе ЗУП, интерактивная таблица, валидация
```

## Сборка файла внешней обработки (`.epf`)

### Вариант 1. Интерактивно через Конфигуратор

1. Запустите **Конфигуратор** базы 1C:ERP или 1С:ЗУП.
2. В главном меню выберите **Файл** → **Новый...** → **Внешняя обработка**.
3. В окне открывшейся обработки нажмите кнопку **Действия** → **Загрузить из файлов...** (или меню **Конфигурация** → **Загрузить конфигурацию из файлов...** для обработки).
4. Укажите файл `src/ЗагрузкаДанныхНДФЛИзЗУП.xml`.
5. Сохраните обработку как `ЗагрузкаДанныхНДФЛИзЗУП.epf` (меню **Файл** → **Сохранить**).

### Вариант 2. Пакетный режим командной строки

```bat
"C:\Program Files\1cv8\8.3.xx.xxxx\bin\1cv8.exe" DESIGNER /F "C:\Bases\ERP" /DisableStartupDialogs /LoadExternalDataProcessorOrReportFromFiles "C:\PathToProject\src" "C:\PathToProject\ЗагрузкаДанныхНДФЛИзЗУП.epf"
```

*Где `C:\PathToProject\src` — каталог с файлом `ЗагрузкаДанныхНДФЛИзЗУП.xml`, а второй путь — результирующий `.epf`.*

### Вариант 3. 1C:Enterprise Development Tools (1C:EDT)

Импортируйте каталог `src` как проект внешней обработки в формате XML выгрузки платформы 1С:Предприятие 8.3.

## Особенности регистра и учетная модель

В типовых конфигурациях ЗУП 3.1 и ERP 2 (подсистема «Зарплата и кадры») регистр учета доходов для целей исчисления НДФЛ:
- **Синоним:** *«Учет доходов для исчисления НДФЛ»* (в обиходе пользователей — «Учет данных для НДФЛ»).
- **Имя объекта метаданных:** `РегистрНакопления.СведенияОДоходахНДФЛ`.
- Также обработка автоматически проверяет наличие вариантов именования `УчетДоходовДляИсчисленияНДФЛ` и `УчетДанныхДляНДФЛ`.

Поскольку регистр накопления в 1С всегда требует документ-регистратор, обработка поддерживает **два метода отражения в ERP**:

1. **Документы «Операция учета НДФЛ» (рекомендуемый):**
   - Документ, предназначенный фирмой 1С специально для ручного и внешнего ввода данных по НДФЛ.
   - Заполняется шапка (Организация, Физическое лицо, Сотрудник, Период регистрации) и табличная часть **«Доходы»** (Дата получения дохода, Код дохода, Категория дохода, Сумма дохода, Код вычета, Сумма вычета, Подразделение, Ставка налогообложения).
   - При установленном флажке «Проводить документы» документ проводится и автоматически формирует системные движения по регистру. Если проведение не удалось из-за специфических контролей базы, документ сохраняется непроведенным с фиксацией причины в журнале.

2. **Документы «Перенос данных» (прямая запись движений):**
   - Создается технический документ `ПереносДанных` с кодом регистратора «НДФЛ».
   - Записи вносятся напрямую в набор записей регистра `РегистрНакопления.СведенияОДоходахНДФЛ` с полным сохранением измерений, ресурсов и реквизитов.

## Требования к COM-соединению

- **Клиентская среда:** Обработка должна быть запущена в **тонком** или **толстом** клиенте Windows. В веб-клиенте прямое COM-соединение платформой не поддерживается (для веб-клиента и Linux предусмотрен встроенный обмен через JSON).
- **Разрядность:** Разрядность запущенного клиента 1С (32-бит или 64-бит) должна совпадать с разрядностью зарегистрированной библиотеки `comcntr.dll` (`V83.COMConnector`).
- **Регистрация коннектора:**
  ```cmd
  regsvr32 "C:\Program Files\1cv8\8.3.xx.xxxx\bin\comcntr.dll"
  ```
  *(или `Program Files (x86)` для 32-битной версии).*
- **Безопасность:** Если в ERP включена защита от опасных действий, разрешите их выполнение при открытии внешней обработки.

## Порядок работы

1. Откройте `ЗагрузкаДанныхНДФЛИзЗУП.epf` в базе 1С:ERP через меню **Файл** → **Открыть**.
2. На вкладке **«1. Подключение к 1С:ЗУП»**:
   - Выберите тип базы: **Файловая** (укажите каталог базы) или **Клиент-серверная** (укажите сервер и имя базы).
   - Введите имя пользователя и пароль к базе ЗУП.
   - Нажмите **«Проверить подключение»** — обработка проверит доступность COM, определит версию конфигурации ЗУП и наличие регистра НДФЛ.
3. На вкладке **«2. Отбор и параметры загрузки»**:
   - Укажите период (с ... по ...).
   - При необходимости задайте отбор по конкретной Организации или Физическому лицу.
   - Выберите способ загрузки в ERP: *«ОперацияУчетаНДФЛ»* или *«ПереносДанных»*.
   - Укажите опции: проводить документы, создавать новые физлица, перезаписывать существующие.
4. Нажмите кнопку **«1. Заполнить из ЗУП»**:
   - Обработка считает данные регистра через COM-запрос к ЗУП и выведет строки в таблицу предпросмотра.
   - Будут подсчитаны итоги: количество строк, общая сумма доходов и сумма вычетов.
5. Проверьте отметки и нажмите **«2. Загрузить в базу ERP»**:
   - Обработка сопоставит справочники, сформирует документы в ERP и зафиксирует статус каждой строки («Загружен» или «Ошибка»).
   - В нижней панели «Журнал сообщений и протокол загрузки» будет доступен подробный лог операций.
6. **Запасной вариант (JSON):**
   - Кнопка «Файл (JSON)» → «Выгрузить в JSON...» позволяет сохранить считанные данные в файл.
   - Кнопка «Загрузить из JSON...» позволяет прочитать файл и выполнить загрузку в базу ERP даже на Linux-клиенте или веб-клиенте без COM.

## Правила сопоставления объектов между ЗУП и ERP

| Объект | Приоритет и правила поиска | Создание нового |
| :--- | :--- | :--- |
| **Организации** | 1) ИНН + КПП<br>2) ИНН (если уникален)<br>3) Точное наименование<br>4) Уникальный идентификатор (GUID) | Нет (требуется предварительное наличие в ERP) |
| **Физические лица** | 1) СНИЛС (СтраховойНомерПФР)<br>2) ИНН<br>3) ФИО + Дата рождения<br>4) Точное ФИО<br>5) Уникальный идентификатор (GUID) | Да, при включенном флажке «Создавать новые физлица» |
| **Сотрудники** | 1) Физлицо + Организация + Табельный номер (Код)<br>2) Физлицо + Организация<br>3) Физлицо<br>4) Уникальный идентификатор (GUID) | Нет (не блокирует проведение, если физлицо найдено) |
| **Виды доходов НДФЛ** | 1) Код дохода (например, `2000`, `2002`, `2010`)<br>2) Наименование | Предопределенный классификатор |
| **Виды вычетов НДФЛ** | 1) Код вычета (например, `126`, `501`)<br>2) Наименование | Предопределенный классификатор |
| **Подразделения** | 1) Наименование в разрезе Организации<br>2) Точное наименование | Нет |
| **Перечисления** | По символическому системному имени значения (через `XMLСтрока` / `Имя`) либо по синониму | Системные перечисления платформы |
