# Перенос исполнительных листов ЗУП → ERP

Внешняя обработка 1С:Предприятие 8.3 для переноса документов **Исполнительный лист** из конфигурации **ЗУП 3.1** в **ERP 2 / КА 2**.

Документы отбираются не «все подряд», а по регистру сведений **Плановые удержания**: в перенос попадают только те исполнительные листы, по которым на дату переноса действует удержание.

## Состав

```
src/
├── ПереносИсполнительныхЛистовЗУПвERP.xml
└── ПереносИсполнительныхЛистовЗУПвERP/
    ├── Ext/ObjectModule.bsl
    └── Forms/Форма/
        ├── Форма.xml
        └── Ext/
            ├── Form.xml
            └── Form/Module.bsl
```

Исходники — иерархическая XML-выгрузка внешней обработки. Сборка в `.epf` выполняется конфигуратором в базе ЗУП или ERP (нужны справочник `Организации` и документ `ИсполнительныйЛист`).

## Сборка .epf

В конфигураторе ЗУП или ERP (пакетный режим):

```
1cv8 DESIGNER /F "<путь к ИБ>" /LoadExternalDataProcessorOrReportFromFiles ^
  "src\ПереносИсполнительныхЛистовЗУПвERP.xml" ^
  "build\ПереносИсполнительныхЛистовЗУПвERP.epf"
```

Либо: **Файл → Открыть** исходники нельзя напрямую; загрузите их командой выше или соберите обработку в EDT.

Запуск: **Файл → Открыть** готовый `.epf` либо регистрация в **Дополнительные отчёты и обработки**. Безопасный режим должен быть выключен (нужны файлы и, опционально, COM).

## Как отбираются документы

На дату переноса строится срез регистра `РегистрСведений.ПлановыеУдержания`.

В выборку входят записи, у которых:

- удержание действует (`Используется = Истина`; если ресурса нет — анализируется `Действие`);
- документ-основание — `ИсполнительныйЛист` либо `ИзменениеУсловийИсполнительногоЛиста` (тогда берётся исходный исполнительный лист);
- документ не помечен на удаление;
- при заполненной организации — только эта организация.

Условия расчёта подставляются из среза `УсловияУдержанияПоИсполнительномуДокументу` на ту же дату, чтобы в ERP попали **текущие** проценты/суммы/доли, а не устаревшие значения шапки.

Если включён флажок «Переносить остаток предела», в реквизит `Предел` записывается остаток регистра накопления `УдержанияДоПределаПоСотрудникам`.

## Режимы работы

| Режим | Где запускать | Что делает |
|---|---|---|
| Выгрузка из ЗУП в файл | ЗУП | Отбор по плановым удержаниям → XML |
| Загрузка в ERP из файла | ERP | Создание/проведение `ИсполнительныйЛист` |
| Прямой перенос через COM | ERP | Чтение ЗУП по COM и запись в текущую базу |

### Типовой сценарий через файл

1. В ЗУП открыть обработку, режим **Выгрузка из ЗУП в файл**.
2. Указать дату переноса (и при необходимости организацию).
3. **Заполнить** — в таблице действующие исполнительные листы.
4. Отметить нужные строки, указать файл, **Выгрузить в файл**.
5. В ERP открыть ту же обработку, режим **Загрузка в ERP из файла**.
6. Указать файл, **Заполнить**, проверить таблицу, **Загрузить в ERP**.

### Прямой перенос

В ERP указать строку подключения к ЗУП (`File=` или `Srvr=` + `Ref=`), **Заполнить**, затем **Перенести через COM**. COM доступен только на Windows.

## Сопоставление ссылок в ERP

| Объект | Порядок поиска |
|---|---|
| Организации | UUID → ИНН+КПП → наименование |
| Физические лица | UUID → СНИЛС → ИНН → ФИО и дата рождения |
| Сотрудники | UUID → табельный номер + физлицо + головная организация |
| Контрагенты (получатели) | UUID → ИНН+КПП → наименование; при включённом флаге создаются |
| Перечисления, тарифы, счета | UUID, имя значения, наименование / номер счёта |

Сотрудники, физлица и организации **не создаются**. Их нужно перенести заранее кадровым обменом. Документ в ERP создаётся с тем же UUID, что в ЗУП.

## Требования

- Платформа 8.3.10+.
- ЗУП 3.1 и ERP 2.4/2.5 (КА 2.4/2.5) с подсистемой зарплаты: документ `ИсполнительныйЛист`, регистр `ПлановыеУдержания`.
- Перед переносом в ERP должны быть организации, сотрудники и физические лица.
